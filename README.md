\# 📚 Book Data Scraper



A Python-based web scraping project that extracts book information from the Books to Scrape website using Requests and BeautifulSoup.



\## 🚀 Features



\- Scrapes book data from multiple pages

\- Automatically handles pagination

\- Extracts book title, price, rating and availability

\- Generates product URLs

\- Handles HTTP request errors

\- Uses a custom User-Agent

\- Exports scraped data to CSV

\- Successfully scraped 1,000 book records



\## 🛠️ Technologies Used



\- Python

\- Requests

\- BeautifulSoup4

\- CSV

\- urllib.parse
